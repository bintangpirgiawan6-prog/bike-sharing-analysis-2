# Proyek Analisis Data Bike Sharing

## Deskripsi
Project ini bertujuan untuk menganalisis pola penyewaan sepeda berdasarkan waktu dan musim menggunakan Bike Sharing Dataset.

## Pertanyaan Bisnis
1. Pada bulan apa jumlah penyewaan sepeda paling tinggi dan paling rendah?
2. Musim apa yang memiliki rata-rata jumlah penyewaan sepeda paling tinggi dan paling rendah?

## Dataset
Dataset yang digunakan terdiri dari:
- day.csv
- hour.csv

## Tahapan Analisis
1. Data Gathering
2. Data Assessing
3. Data Cleaning
4. Exploratory Data Analysis
5. Data Visualization
6. Kesimpulan dan Rekomendasi

## Kesimpulan
Hasil analisis menunjukkan adanya perbedaan jumlah penyewaan sepeda berdasarkan bulan dan musim. Informasi ini dapat digunakan untuk membantu pengelola layanan bike sharing dalam merencanakan ketersediaan sepeda dan strategi operasional.
