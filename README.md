# Bike Sharing Data Analysis

## Deskripsi Proyek
Proyek ini bertujuan untuk menganalisis pola penyewaan sepeda berdasarkan bulan dan musim menggunakan Bike Sharing Dataset. Analisis dilakukan untuk memahami tren penyewaan sepeda dan menghasilkan insight yang dapat membantu pengambilan keputusan operasional.

## Business Questions
1. Pada bulan apa jumlah penyewaan sepeda paling tinggi dan paling rendah?
2. Musim apa yang memiliki rata-rata jumlah penyewaan sepeda paling tinggi dan paling rendah?

## Dataset
Dataset yang digunakan berasal dari Bike Sharing Dataset, yang terdiri dari:
- `day.csv` — Data penyewaan sepeda harian.
- `hour.csv` — Data penyewaan sepeda per jam.

## Tahapan Analisis
1. **Data Gathering** — Mengumpulkan dan memuat dataset.
2. **Data Assessing** — Memeriksa struktur, tipe data, dan kualitas data.
3. **Data Cleaning** — Menangani permasalahan data jika ditemukan.
4. **Exploratory Data Analysis (EDA)** — Mengeksplorasi pola dan tren penyewaan sepeda.
5. **Data Visualization** — Menyajikan hasil analisis dalam bentuk visualisasi.
6. **Conclusion and Recommendations** — Menyusun kesimpulan dan rekomendasi berdasarkan hasil analisis.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Streamlit

## Kesimpulan
Analisis ini berfokus pada perbandingan jumlah penyewaan sepeda berdasarkan bulan dan musim. Hasil analisis diharapkan dapat memberikan gambaran mengenai periode dengan permintaan tinggi dan rendah sehingga dapat membantu pengelola layanan bike sharing dalam merencanakan ketersediaan sepeda dan strategi operasional.
